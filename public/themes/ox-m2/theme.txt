Description:

OX M2 is a glass-style HyperOS theme focused on customization, especially the lock screen and home screen. It uses rounded elements, translucent panels, large clocks, customizable widgets, and colorful system icons.

The lock screen has multiple built-in wallpapers and several customization options. You can change the clock style, date format, colors, widgets, wallpaper effects, and other lock screen settings. It also supports depth effects, gravity effects, wallpaper blur, dark overlay, and other visual options.

The home screen uses rounded circular icons with different color styles and a large collection of customizable clock and information widgets. The main glass-style widget has multiple faces and can display different types of information.

The Control Center has been redesigned with an 8-tile layout and translucent controls, while keeping the same clean style as the rest of the theme.
